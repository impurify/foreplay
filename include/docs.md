`DEFAULT_LANG`
: Default language for all documents, *e.g.*, `en`.

`SITE_TITLE_PRE`
: The delimiting string before the site’s title in the `<title>` element, to separate it from the page’s title and subtitle.  This needs to include any space between the two titles.  When there is no page title, such as on the homepage, this will disappear.

`SITE_TITLE`
: The site’s title.

`SITE_TITLE_POST`
: The delimiting string, if any, after the site’s title in the `<title>` element.  *E.g.*, if parentheses are used to delimit the title, this is `)`.
